# 🗃️ پروژه آموزشی SQLite3 در پایتون

این پروژه یک راهنمای کامل برای کار با پایگاه داده SQLite3 در پایتون است که شامل ۱۰ تمرین آموزشی می‌باشد.

## 📋 فهرست تمرین‌ها

### تمرین ۱: ایجاد و اتصال به پایگاه داده
- **۱.۱** ایجاد پایگاه داده جدید با نام `test.db`
- **۱.۲** ایجاد جدول `employees` با ستون‌های:
  - `id` (عدد صحیح - کلید اصلی)
  - `name` (متن - اجباری)
  - `age` (عدد صحیح)
  - `department` (متن)

### تمرین ۲: درج داده
- **۲.۱** ایجاد تابع برای درج کارمند جدید
- **۲.۲** درج ۵ کارمند نمونه در جدول

### تمرین ۳: بازیابی داده
- **۳.۱** نمایش تمام رکوردهای جدول کارمندان
- **۳.۲** نمایش کارمندانی از یک دپارتمان خاص

### تمرین ۴: به‌روزرسانی داده
- **۴.۱** به‌روزرسانی دپارتمان کارمند بر اساس ID
- **۴.۲** اعمال تغییرات روی ۲ کارمند و نمایش نتایج

### تمرین ۵: حذف داده
- **۵.۱** حذف کارمند بر اساس ID
- **۵.۲** حذف یک کارمند و نمایش لیست باقی‌مانده

### تمرین ۶: کوئری‌های پیشرفته
- **۶.۱** نمایش کارمندانی با سن بیشتر از مقدار مشخص
- **۶.۲** نمایش کارمندانی که نام آن‌ها با حرف خاصی شروع می‌شود

### تمرین ۷: مدیریت تراکنش‌ها
- **۷.۱** درج چندکارمند در یک تراکنش (قابلیت Rollback)
- **۷.۲** به‌روزرسانی سن چندکارمند در یک تراکنش

### تمرین ۸: ایجاد روابط بین جداول
- **۸.۱** ایجاد جدول `departments` با ستون‌های `id` و `name`
- **۸.۲** اضافه کردن کلید خارجی به جدول `employees`
- **۸.۳** درج داده با حفظ یکپارچگی ارجاعی

### تمرین ۹: ایندکس‌گذاری و بهینه‌سازی
- **۹.۱** ایجاد ایندکس روی ستون `name`
- **۹.۲** مقایسه عملکرد جستجو با زمان‌سنجی

### تمرین ۱۰: پشتیبان‌گیری و بازیابی
- **۱۰.۱** پشتیبان‌گیری از پایگاه داده در فایل `backup.db`
- **۱۰.۲** بازیابی پایگاه داده از فایل پشتیبان

## 🛠️ تکنولوژی‌های استفاده شده

- **Python 3.9.7+**
- **SQLite3** (ماژول استاندارد پایتون)
- **shutil** برای عملیات فایل
- **time** برای اندازه‌گیری عملکرد
